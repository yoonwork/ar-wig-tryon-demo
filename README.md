# 브라우저 AR 가발 체험 데모 (제안용 데모 · 예시)

위시켓 159067 「3D AR 가발 체험 앱」 지원용으로 직접 만든 데모예요. 휴대폰이나 PC 브라우저에서 앱 설치 없이 바로 열려요.
얼굴을 비추면(또는 예시 사진을 고르면) 코드로 만든 3D 가발이 머리 위치·방향에 맞춰 씌워져요.

- 열기: 이 폴더를 https로 올린 주소(예: GitHub Pages). 카메라는 https 또는 localhost에서만 켜져요.
- 로컬 확인: 이 폴더에서 `python3 -m http.server 8000` → `http://localhost:8000`
  (`index.html`을 더블클릭하면 브라우저가 js 모듈을 막아서 안 열려요.)
- 확인용 주소 옵션: `?mode=photo&photo=1&wig=long` (사진 0·1·2, 가발 dandy·part·long·bob), `&dim=0`(흐림 끔), `&mesh=1`(얼굴 메시 보기), `&fit=104`(가발 크기 %)

## 이 데모가 보여 주는 것 4가지 (DeepAR 테스트에서 아쉬웠던 점)

1. **질감·볼륨감 (평면·만화 같은 느낌)**
   - 가발을 그림 한 장이 아니라 8천~1만 4천 가닥으로 길러요. 두피에 뿌리를 심고 빗질 방향·중력·두상 충돌을 따라 가닥을 만들고, 가닥을 묶음(clump)으로 모아 결이 보이게 했어요. 묶음마다 크기·조임·밝기가 다르고, 큰 묶음 끝은 2~3갈래로 모이며, 가늘고 옅은 잔머리가 조금 섞여요.
   - 가닥 굵기는 뿌리→끝으로 가늘어지고 가닥마다 달라요. 헤어라인 가장자리는 숱이 점점 줄고 뿌리가 아주 가늘게 시작해요.
   - 셰이더: 결 방향 이방성 반사(Kajiya-Kay, 반사 2개를 뿌리·끝 쪽으로 엇갈리게), 뿌리는 어둡고 끝은 옅게, 숱 깊이 그림자(겉면에서 묻힌 깊이를 미리 구운 간이 deep opacity)와 아랫면 그림자.
   - 장면 밝기·빛 방향을 얼굴 피부 밝기로 추정해서 가발 밝기를 맞춰요.
2. **이마·옆머리·귀 경계**
   - 표준 얼굴 메시(468점) + 두개골 타원체 + 목·턱 아래로 만든 '보이지 않는 가림막(occluder)'이 깊이만 써서, 가발 뒤쪽이 얼굴 앞으로 튀어나오지 않아요.
   - 헤어라인 뿌리는 투명하게 시작하고, 두피 덮개는 헤어라인에서 점점 옅어져요. 헤어라인 아래와 앞머리 밑에는 머리카락이 가리는 정도만큼 얇은 그림자가 생겨요.
   - 짧은 머리는 귀 위·구레나룻에서 커트 라인을 따로 잡아 귀가 드러나요.
3. **좌우 60° 측면 정합성**
   - MediaPipe Face Landmarker의 얼굴 변환 행렬(4×4)로 머리 위치·방향을 잡고, One Euro 필터로 떨림을 줄였어요.
   - MediaPipe는 세로 화각 63°를 가정해요. 실제 렌즈가 더 좁으면(가로 웹캠 약 45°, 인물 사진 약 26°) 뒤통수가 작게 그려져서, 얼굴 크기·위치는 그대로 두고 거리만 늘려 원근을 렌즈에 맞췄어요. 이걸 안 하면 측면에서 가발이 머리보다 작고 앞으로 쏠려 보였어요.
   - 화면 위에 현재 고개 각도(yaw)를 숫자와 눈금(±60°)으로 보여 줘요. 예시 사진 중 하나는 고개를 57° 돌린 사진이에요.
4. **본인 머리카락 흐림 (공고의 미확정 범위)**
   - MediaPipe Image Segmenter의 머리카락 분할 모델로 내 머리카락 영역을 찾아, 주변의 '머리카락이 아닌' 색으로 채우고 흐려요(간단한 인페인팅). 얼굴에서 먼 곳(정수리 위·뒤통수)은 배경·옷 색만, 얼굴 가까운 곳(관자놀이·구레나룻)은 피부색도 써요. 턱·수염은 제외해요.
   - 마스크는 부드럽게 흐린 뒤 두 겹으로 넓혀서, 잔머리 가장자리의 옅은 윤곽까지 덮어요. 가발 두상이 화면에서 차지하는 윤곽을 매 프레임 계산해, 그 밖은 두상에서 더 먼 쪽 배경색만 써서 채워요(귀 위·관자놀이 옆의 흰 윤곽 방지).
   - '내 머리 흐림' 스위치로 켜고 끌 수 있고, '누르면 원래 모습'으로 바로 비교해요.

## 실제 앱에서는 (Flutter + 상용 SDK)

1. 화면 5개(시작·체험·가발 선택·촬영 결과·설정)는 Flutter로 만들고, 얼굴 추적과 3D 렌더링은 후보 상용 AR SDK(DeepAR, Banuba 등) 중 같은 각도·조명 측면 테스트로 고른 SDK의 Flutter 연동을 써요.
2. 이 데모의 가림막(얼굴 메시 + 두상), 결 방향 반사 셰이더, 헤어라인 페이드·그림자를 SDK의 3D 장면·셰이더로 옮기고, 제공 가발 10종은 가닥 카드(hair card) 메시로 변환해 가발마다 위치·크기를 맞춰요.
3. 내 머리 흐림은 SDK의 헤어 분할 기능(제공 여부 확인 필요) 또는 MediaPipe 머리카락 분할 모델(Android·iOS 네이티브 지원)로 같은 방식의 블렌드를 넣어요.

## 화면 흐름

시작(카메라 사용 안내) → 체험(하단 남성/여성 가발 목록 즉시 전환, 색 3가지, 내 머리 흐림, 원래 모습 비교, 고개 각도) → 촬영 결과(앨범에 저장, 다시 찍기). 설정 시트(fps 표시, 얼굴 메시 보기, 가발 크기 맞춤, 약관·개인정보·버전 자리)와 '이렇게 확인해 보세요' 안내 시트가 있어요.

- 시작 화면 3D 미리보기: 카메라 권한이나 AI 모델 없이, 얼굴 없는 마네킹 두상에 체험 화면과 같은 가닥 가발을 씌워 좌우 60°로 천천히 돌려요. 손가락(마우스)으로 끌면 돌아가고, 아래 칩으로 가발 4종을 바로 바꿔 봐요. 고른 가발로 체험이 시작돼요.
  - 마네킹은 두개골 타원체(가발을 기른 그 두상) + 턱 + 코 + 목을 부드럽게 합친 거리 함수로 만들고, 가발마다 머리카락이 드리우는 그림자를 꼭짓점에 구워요.
- 가발 바꾸기: 아래 목록, 체험 화면을 좌우로 밀기, PC에서는 ← → 키. 바꿀 때 머리카락이 뿌리에서 끝으로 흘러내리며 나타나요(0.7초).
- AI 모델 받는 동안 실제 받은 양을 막대와 숫자로 보여 줘요(약 15.7MB, 처음 한 번만).
- 촬영: 셔터를 누르면 화면이 한 번 번쩍이고, 결과 위에 가발·색·사진 이름을 적어요. 아래 가발 목록에 가려 안 보이던 부분은 빼고 화면에 보이던 만큼만 저장해요.

## 파일

- `index.html` — 화면(시작·체험·결과·설정·안내)과 스타일
- `js/app.js` — 화면 흐름, 카메라·사진 입력, 추적·분할 실행, 배경(내 머리 흐림) 셰이더, 촬영
- `js/hero.js` — 시작 화면 3D 미리보기(마네킹 두상 + 가발, 자동 회전·끌어서 돌리기)
- `js/hair.js` — 가발 스타일 정의, 가닥 생성, 머리카락·두피 덮개·얼굴 그림자 셰이더
- `js/head.js` — 두상 타원체, 헤어라인, 충돌 몸체, 가림막
- `js/filter.js` — One Euro 필터
- `js/canonical.js` — MediaPipe 표준 얼굴 메시 데이터

## 한계 (솔직하게)

- 진짜 가발 사진처럼 보이지는 않아요. 가닥은 화면을 향한 얇은 띠라서 아주 가까이서 보면 결이 고르게 보이고, 물리 시뮬레이션(흔들림)은 없어요.
- 두상은 평균 크기 타원체라서 머리가 크거나 숱이 많으면 가발 밖으로 내 머리가 보여요(설정의 '가발 크기 맞춤'과 '내 머리 흐림'으로 줄여요).
- 내 머리 흐림은 간단한 인페인팅이라, 밝은 배경에서는 흐린 자국이 남을 수 있어요.
- 휴대폰 실기기의 fps와 60° 회전은 헤드리스 브라우저로 확인하지 못했어요(확인 필요). 느린 기기에서는 3초 동안 22fps 아래면 해상도를 자동으로 낮춰요.
